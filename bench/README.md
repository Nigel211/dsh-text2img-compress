# 准确率基准（Accuracy Benchmark）

插件核心假设：**18px/800×800/384-token 的密度下，视觉模型能高保真读取图片中的文字**。
发布前建议跑一轮基准，把结果写进 README 的"实测"表，供用户挑选字号。

## 方法

1. **样本**（每类 ≥ 3 段，每段 1500~10000 字）：
   - 中文散文/新闻长文
   - 中英混合技术文档（含模型名、URL、分数）
   - 代码片段（JSON / Python / diff）
   - 表格化文本（每行一条数据）
2. **流程**：开启「图·开」→ 逐段发送 → 让模型**逐字逐段复述**或**抽 20 个关键点回答**；
3. **评分**：字符级准确率（edit distance / 原文长度）＋ 关键点命中率；
4. **基线**：同一段文本以**纯文本**发送并复述，作为 100% 参照。

## 实测记录（2026-08）

- 样本：DeepSeek 官网中文写作示例《端午咸》（约 1,000 字，纯中文散文），18px；
- 结果：**1,036 字 = 804 token**（DeepSeek-V3 tokenizer 实测）→ 渲染 **1 页 = 384 token（约 2.1×）**；
  同一模型家族读取该页，**内容逐字对应**。
- 补充：DeepSeek 官方更新日志（约 9000+ 字/7 页 @18px）回读同样 100% 对应，
  但文本侧按真实 tokenizer 计约 7000 token，压缩约 **2.6×**（早期按 1 字=1 token 估算的
  4~5× 偏高，已修正）。
